AI 101 — Day 1: Python Revision Notes
Quick revision · 35 minutes · AI & automation focused
These notes are designed for someone who already knows Python basics. Focus on refreshing syntax, understanding when to use each feature, and remembering how these concepts apply to AI projects.

1. Python data structures
Python provides four commonly used built-in collection types.

Type	Ordered	                Mutable	Allows duplicates
list	Yes	                    Yes	    Yes
tuple	Yes	                    No	    Yes
set	    No guaranteed order	    Yes	    No
dict	Yes(insertion order)	Yes	    Keys are unique

Lists — ordered, changeable collections
tasks = ["clean data", "train model", "test model"]
tasks.append("deploy model")
tasks.remove("test model")
print(tasks[0])       # clean data
print(len(tasks))     # 3

Remember:
    - append() adds one item.
    - extend() adds multiple items from an iterable.
    - pop() removes and returns an item.
    - Slicing: tasks[0:2].
AI use: storing predictions, data samples, labels, and model outputs.

Dictionaries — key-value pairs
prediction = {    "label": "cat",    "confidence": 0.97}
print(prediction["label"])
print(prediction.get("score", 0))

Remember:
    - dict[key] accesses a value but raises KeyError if the key is missing.
    - get() lets you provide a default.
    - items() returns key-value pairs.
    - Keys must be hashable; strings and numbers are common choices.
AI use: storing API responses, model predictions, configurations, and metadata.


Sets — unique elements
labels = ["cat", "dog", "cat", "bird"]
unique_labels = set(labels)
print(unique_labels)
print("cat" in unique_labels)

Remember:
    - Automatically removes duplicates.
    - Supports union (|), intersection (&), and difference (-).
    - Doesn't support indexing like a list.
AI use: finding unique labels, removing duplicates, and comparing categories.

Tuples — fixed collections
image_size = (224, 224, 3)
height, width, channels = image_size

Remember:
- Tuples cannot be reassigned item by item.
- Useful for fixed records and unpacking.
- A single-item tuple requires a trailing comma: (5,).
AI use: representing image dimensions, coordinates, and fixed configuration values.

2. Conditions and loops
Conditions
accuracy = 0.92
if accuracy >= 0.95:
    print("Excellent")
elif accuracy >= 0.80:
    print("Acceptable")
else:
    print("Needs improvement")

Operators to remember:
Category	Operators
Comparison	==, !=, >, <, >=, <=
Logical	and, or, not
Membership	in, not in
Identity	is, is not
Important: use == to compare values. Use is primarily to check object identity, such as value is None.


Loops
scores = [0.8, 0.92, 0.75]
for score in scores:
    print(score)

Useful loop patterns:
for i, score in enumerate(scores):
    print(i, score)
    
for i in range(5):
    print(i)

    - enumerate() provides an index and value.
    - range() generates a sequence of integers.
    - break exits a loop.
    - continue skips to the next iteration.
AI use: iterating through predictions, processing batches, and filtering records.


3. Functions and modules
Functions
Functions let you reuse logic instead of repeating code.
def calculate_average(scores):
    if not scores:
        return 0    
    return sum(scores) / len(scores)
    
print(calculate_average([80, 90, 100]))


Remember:
    - def defines a function.
    - Parameters receive input.
    - return sends a result back.
    - print() displays output; it does not replace return.
    - Default arguments should generally use immutable values.
def greet(name="Developer"):
    return f"Hello, {name}!"


Modules
A module is a Python file containing reusable code.
utils.py
def count_words(text):
    return len(text.split())



main.py
from utils import count_words
print(count_words("Python is useful for AI"))


Useful imports:
import json
import pathlib
from collections import Counter



AI use: separating data processing, model logic, and application code into reusable files.

4. File handling
Python uses open() to work with files.
with open("sample.txt", "r", encoding="utf-8") as file:
    content = file.read()print(content)



File modes
Mode	Purpose
"r"	Read
"w"	Write; replaces existing content
"a"	Append
"x"	Create a new file; fails if it exists
"rb"	Read binary data
Prefer with open(...) because it closes the file automatically.
Writing a file
with open("output.txt", "w", encoding="utf-8") as file:    file.write("AI 101 - Day 1")



Using pathlib
from pathlib import Path
path = Path("sample.txt")
if path.exists():
    content = path.read_text(encoding="utf-8")

pathlib makes file paths easier to work with across operating systems.

AI use: loading datasets, reading prompts and configuration files, and saving generated results.

5. JSON processing
JSON is a common format for structured data and API communication.
Python and JSON
Python	JSON
dict	Object
list	Array
str	String
int, float	Number
True, False	true, false
None	null
Read JSON
import json
with open("tasks.json", "r", encoding="utf-8") as file:
    tasks = json.load(file)
    print(tasks[0]["task"])



Write JSON
with open("output.json", "w", encoding="utf-8") as file:
    json.dump(tasks, file, indent=4)



Remember:
- json.load() reads JSON from a file.
- json.loads() parses a JSON string.
- json.dump() writes JSON to a file.
- json.dumps() converts Python data into a JSON string.
AI use: processing API responses, exchanging data between services, and storing structured model outputs.

6. Exception handling
Exceptions allow your program to respond to errors instead of crashing unexpectedly.
try:
    number = int(input("Enter a number: "))
    print(100 / number)

except ValueError:
    print("Enter a valid integer.")

except ZeroDivisionError:
    print("Cannot divide by zero.")


Important keywords
Keyword	Purpose
try	    Code that might fail
except	Handle a specific error
else	Runs if no exception occurred
finally	Runs whether an exception occurred or not
raise	Raise an exception intentionally

File example
try:
    with open("data.txt", "r", encoding="utf-8") as file:
            content = file.read()
except FileNotFoundError:
    print("Input file does not exist.")


Remember: catch specific exceptions rather than using a bare except:.
AI use: handling missing datasets, invalid user inputs, malformed API responses, and failed file operations.

7. Classes and objects
A class groups related data and behavior.
class FileProcessor:

    def __init__(self, filename):
        self.filename = filename

    def read_file(self):
        with open(self.filename, "r", encoding="utf-8") as file:
            return file.read()


processor = FileProcessor("sample.txt")
content = processor.read_file()

Remember:
- A class defines a type of object.
- An object is an instance of a class.
- __init__() initializes an object.
- self refers to the current instance.
- Methods are functions defined inside a class.
AI use: organizing model configurations, prediction services, data processors, and reusable application components.
You don't need inheritance or advanced OOP for today's utility.

8. Virtual environments and packages
A virtual environment isolates a project's installed Python packages from other projects.
Commands to remember
# Create an environment
python -m venv .venv

# Activate on Windows Git Bash
source .venv/Scripts/activate

# Install a package
python -m pip install requests

# List installed packages
python -m pip list

# Save dependencies
python -m pip freeze > requirements.txt

# Install dependencies later
python -m pip install -r requirements.txt


Deactivate when finished:
deactivate


Git reminder
Add this to .gitignore:
.venv/
__pycache__/
*.pyc


Do not commit your entire virtual environment. Commit your source code and dependency information instead.
AI use: keeping project dependencies isolated, especially when different AI projects require different library versions.
