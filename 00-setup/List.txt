Python Lists — Essential Revision Notes
AI 101 · Day 1 · Quick reference

1. What is a list?
A list stores multiple items in a single variable.
numbers = [10, 20, 30, 20]

    - Ordered: items maintain their position.
    - Mutable: you can change, add, or remove items.
    - Allows duplicates.
    - Can contain different data types.
2. Accessing and modifying elements
numbers = [10, 20, 30, 40]

numbers[0]      # 10 (first item)
numbers[-1]     # 40 (last item)
numbers[1:3]    # [20, 30] (slicing)

numbers[0] = 5  # Change first item

Remember: Indexing starts at 0. The ending index in a slice is excluded.
3. Essential list methods
Method	Purpose
append(x)	Add one item to the end
extend(iterable)	Add multiple items
insert(i, x)	Insert at a specific index
remove(x)	Remove the first matching value
pop()	Remove and return the last item
pop(i)	Remove and return item at index i
index(x)	Find the first matching index
count(x)	Count occurrences
sort()	Sort the original list
reverse()	Reverse the original list
clear()	Remove all items
copy()	Create a shallow copy
4. Useful built-in functions
These are functions, not list methods.
Function	Purpose
len(numbers)	Number of elements
sum(numbers)	Sum of numeric elements
min(numbers)	Smallest element
max(numbers)	Largest element
sorted(numbers)	Return a new sorted list
5. Looping through a list
tools = ["Python", "OpenCV", "PyTorch"]

for tool in tools:
    print(tool)

With index:
for i, tool in enumerate(tools):
    print(i, tool)

6. List comprehension
A concise way to create a new list from an iterable.
numbers = [1, 2, 3, 4, 5]

squares = [n**2 for n in numbers if n % 2 == 0]

print(squares)  # [4, 16]

Useful for filtering and transforming data.
7. Important things to remember
    - append([3, 4]) adds a nested list as one element; extend([3, 4]) adds the elements individually.
    - remove(x) removes by value; pop(i) removes by index.
    - sort() changes the original list; sorted() returns a new list.
    - pop() on an empty list raises IndexError.
    - remove() and index() raise ValueError if the value is absent.
8. AI applications
Lists are commonly used to store:
    - Model predictions and confidence scores.
    - Dataset samples and labels.
    - Image-processing results.
    - Collections of tasks or API results.
