# AI 101 — Complete Learning Roadmap

**Duration:** 101 days  
**Goal:** Build strong Applied AI foundations and develop practical AI automation projects.

## Challenge Objectives

- Understand how modern AI and LLMs work.
- Learn prompting, embeddings, RAG, and AI agents.
- Build practical AI-powered automation projects.
- Learn evaluation, deployment, and production practices.
- Complete a capstone project and document the journey.

## Stage 0 — Setup and Foundations (Days 1–3)
- Set up the development environment and GitHub repository.
- Refresh Python fundamentals.
- Learn Git basics and establish a learning workflow.

## Stage 1 — AI and LLM Foundations (Days 4–15)
- Understand machine learning and deep learning fundamentals.
- Learn neural networks, transformers, and LLM concepts.
- Practice prompting and structured outputs.
- Understand embeddings and introductory RAG.

## Stage 2 — Tools and AI Agents (Days 16–25)
- Learn tool/function calling.
- Understand agent workflows and control loops.
- Explore agent frameworks and build a basic tool-using agent.

## Stage 3 — Evaluation and Reliability (Days 26–35)
- Learn how to evaluate AI outputs.
- Explore hallucinations, failure cases, and guardrails.
- Create test cases and measure system performance.

## Stage 4 — RAG Engineering (Days 36–47)
- Learn document ingestion and chunking.
- Explore embeddings, vector databases, and retrieval.
- Build and improve a document-question-answering system.

## Stage 5 — Multimodal AI (Days 48–61)
- Explore image, audio, and other multimodal inputs.
- Build practical multimodal AI workflows.
- Understand where multimodal systems are useful.

## Stage 6 — Production AI Systems (Days 62–75)
- Build APIs with FastAPI.
- Learn Docker and deployment fundamentals.
- Explore monitoring, security, and reliability.
- Integrate AI systems with existing software.

## Stage 7 — Applied Machine Learning (Days 76–87)
- Refresh core ML workflows.
- Work with data, model training, and evaluation.
- Build a small applied ML project.

## Stage 8 — Capstone Project (Days 88–100)
- Define a practical problem and project requirements.
- Design and build an AI-powered application.
- Integrate relevant AI, automation, and backend components.
- Test, document, and prepare the project for demonstration.

## Stage 9 — Final Challenge (Day 101)
- Complete a final practical AI challenge.
- Review the skills and concepts learned.
- Document outcomes, gaps, and next steps.

## Learning Resources

Use the resources selected for each day in the original AI 101 learning plan:

- Python and Pro Git documentation
- Google Machine Learning resources
- Hugging Face LLM Course and Agents Course
- DeepLearning.AI courses on prompting, embeddings, vector databases, RAG, and AI systems
- Full Stack Deep Learning
- FastAPI, Docker, Spring Boot, and GitHub Actions documentation

## Daily Learning Cycle

1. Learn the assigned concepts.
2. Practice with code or exercises.
3. Record concise notes in the day's folder.
4. Build or improve something practical.
5. Review what you learned and identify gaps.
6. Commit your work to GitHub.

## Progress Tracking

Track daily completion, practical exercises, projects, and reflections separately in the repository.
