> A 101-day hands-on journey to build practical skills in Applied AI, LLMs, Automation, and AI Engineering.

## About

AI 101 is my personal 101-day learning challenge.

The goal is not to simply complete courses or collect certificates.

The goal is to:

**Learn → Build → Test → Evaluate → Improve → Deploy → Explain**

# Major Projects

## Stage 01 — Structured AI Extraction

Build an application that converts messy emails or text into validated structured JSON.

Skills:

- LLM APIs
- Prompting
- Structured outputs
- Pydantic
- Validation
- Retries

---

## Stage 02 — AI Automation

Build an email or lead-triage automation that:

- Processes incoming information.
- Uses an LLM for classification/extraction.
- Logs results to Google Sheets.
- Demonstrates both code-based and n8n-based automation.

---

## Stage 03 — Evaluation System

Create a 30–50 case evaluation dataset for the automation.

Measure:

- Correctness
- Extraction quality
- Classification quality
- Failure categories
- Changes after prompt modifications

---

## Stage 04 — RAG Application

Build a document Q&A system with:

- Document parsing
- Chunking
- Embeddings
- Vector search
- Metadata
- Retrieval
- Citations
- "I don't know" behavior
- Evaluation

---

## Stage 05 — Multimodal Extraction

Build an invoice/document extraction system using:

- OCR
- Vision models
- Image preprocessing
- Structured outputs
- Confidence checks
- Human-review fallback

---

## Stage 06 — Production AI Application

Take one of the strongest projects and make it production-oriented.

Include:

- API
- Validation
- Error handling
- Logging
- Tests
- Docker
- CI
- Deployment
- Cost/latency considerations
- Security considerations

---

## Stage 07 — Applied ML

Build a small baseline ML model and understand when different approaches should be used:

```text
Prompting
    vs
RAG
    vs
Fine-tuning
    vs
Traditional ML
```

---

## Stage 08 — AI Product & Freelance Skills

Learn how to turn technical capability into a clearly scoped deliverable.

Practice:

- Problem discovery
- Scope definition
- Estimation
- Pricing models
- Proposals
- Scope control
- Handover documentation
- Case studies

---

## Stage 09 — Independent Capstone

Design and build an AI solution for a realistic business problem.

The project must be independently planned and implemented.

Expected deliverables:

- Problem definition
- Requirements
- Architecture
- Working application
- Evaluation
- Deployment
- Documentation
